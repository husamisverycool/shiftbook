# Decision records

Any change to the stack in SPEC §3, or any significant technical choice, gets a record here:
`NNNN-short-title.md`, numbered in order, never edited after acceptance (supersede it with a new one).

## Template

```
# NNNN — Title

Status: proposed | accepted | superseded by NNNN
Date: YYYY-MM-DD

## Context
What problem forces a decision.

## Decision
What we chose.

## Alternatives considered
What else, and why not.

## Consequences
What gets easier, what gets harder, what we must watch.
```
