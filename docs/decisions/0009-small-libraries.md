# 0009 — Small libraries added in slice (a)

Status: accepted
Date: 2026-10-15

## Context
Slice (a) needs to read many file types and produce files.

## Decision
- `sharp`: image resize, rotate, crop, redaction painting.
- `heic-convert`: iPhone photos (HEIC) to JPEG.
- `pdfjs-dist` + `@napi-rs/canvas`: render PDF pages to images; read PDF text in tests.
- `csv-parse`, `exceljs`: time-clock and VMS exports.
- `fflate`: the demo's sample-timesheet .zip download.
- shadcn/ui components (Base UI primitives, lucide icons) as generated by the shadcn CLI.

## Alternatives considered
Shelling out to system tools (ImageMagick, poppler): not present in every hosting environment.

## Consequences
Native packages (`sharp`, `@napi-rs/canvas`) are listed in `serverExternalPackages`.
