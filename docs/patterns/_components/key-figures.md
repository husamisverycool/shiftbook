# Pattern: Figures (shared component)

Status: adopted — decision 0029 (2026-10-16, revised after the owner's review)
Reference product and screen: Stripe Dashboard Home ("Today"); Stripe app overview page ("Program
summary"); Mercury Insights and Transactions
Source URL: https://support.stripe.com/questions/dashboard-home-page-charts-for-business-insights
Source URL: https://docs.stripe.com/stripe-apps/patterns/chart-layout
Source URL: https://mercury.com/blog/introducing-insights
Source URL: https://mercury.com/blog/updated-transactions-page
Researched: 2026-10-16 from the screenshots themselves (part C). Confidence: high.

## Hierarchy
1. Plain type, never in a box: a small muted label over the figure; the figure large, semibold,
   with tabular digits; a short muted line under it only where the page's reference has one (Stripe
   Home: "3:30 PM"; "previous period").
2. Set in a row with generous space between figures (Stripe "Program summary"); a right column of
   figures separated by hairlines, each with a "View" link, as Stripe Home's balance and payouts.
3. Used only on pages whose reference shows figures: Home, Margin, Receivables.

## Never
A grid of bordered boxes each with a caption, a number and a sentence.

## Colour (decision 0046)

A "strong" size, 24px semibold, for the headline figures of Home, Margin and Receivables (decision 0046).

Deviations allowed: none
