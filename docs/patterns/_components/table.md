# Pattern: Tables (shared component)

Status: adopted — decision 0029 (2026-10-16)
Reference product and screen: Stripe Dashboard — invoices list
Source URL: https://docs.stripe.com/invoicing/dashboard
Source URL: https://vercel.com/geist/table
Researched: 2026-10-16 from the screenshot itself (part C). Confidence: high.

## Hierarchy
1. The table runs the page's full width with no box around it; a hairline under the header row and
   between rows.
2. Column headers in small capitals, semibold, on the page's own background.
3. Rows about 48px; the amount bold with tabular digits; muted secondary values; "—" for an empty
   value (Stripe; Geist).
4. A "…" menu at the row's end for its actions (Stripe).

Deviations allowed: none
