# Pattern: One pay stub (`/w/pay/[id]`)

Status: adopted — slice t (2026-10-17)
Reference product and screen: Gusto pay stub (employer and employee information with the pay period;
earnings with rate, hours, current and year to date; gross pay)
Source URL: https://gusto.com/resources/articles/payroll/how-to-read-your-pay-stub
Source URL: https://support.gusto.com/article/260428150612093/view-and-understand-your-paystub-for-us-employees
Researched: 2026-10-17. Confidence: high.

## Hierarchy
1. Back to **Pay**; title: the week worked; the gross as a large figure.
2. **Pay period**: the agency, the worker, the dates.
3. **Earnings**: one row per earning type (Regular, Overtime, Double time, Holiday, …): rate, hours,
   current amount; then **Gross pay** with the year to date beside it.
4. The line about taxes and deductions; **Download PDF** (`_documents/pay-stub.md`).

Deviations allowed: none
