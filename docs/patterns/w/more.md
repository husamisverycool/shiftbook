# Pattern: More (`/w/more`)

Status: adopted — slice t (2026-10-17)
Reference product and screen: Gusto mobile app More (Documents) and Profile (personal information,
tax elections)
Source URL: https://support.gusto.com/article/207607681100000/gusto-mobile-app-employee-experience
Researched: 2026-10-17. Confidence: high.

## Hierarchy
1. The worker's name and phone (masked).
2. **Documents**: the signed onboarding forms (Form W-4, Form I-9 Section 1, direct deposit
   authorization) each with **Download**.
3. **Onboarding** (progress, link to continue).
4. **Language**: English · Español.
5. **Sign out**.

Deviations allowed: none
