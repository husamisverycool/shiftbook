# Pattern: Website security (tabulado.com/security)

Status: adopted — slice aa, second design (2026-10-20)
Reference product and screen: Mercury's security band made a page (dark, its ring render behind a
centred heading), Resend's honest status row (as frosted tiles), Mercury's label-left groups of plain
facts on the light page, Resend's responsible disclosure, Mercury's questions and centred close.
Source URL: https://mercury.com/security
Source URL: https://resend.com/security
Researched: 2026-10-20 (`docs/research/website-visual-slice-aa.md`). Confidence: medium.

## Hierarchy
1. Dark band: concentric rings fading out behind a small uppercase label, the h1 and one sentence; four
   frosted status tiles (in place / not yet, never overstated).
2. Groups of controls: each group's title at the left, its facts at the right, hairlines between.
3. Report a problem (only when a contact address is set).
4. Questions: heading at the left, accordion at the right.
5. Dark close with the two pills; then the footer.

## Interactions
- Questions open with the plus turning to a cross.

## States
- No contact address: the report group is hidden. No demo address: the demo pill is hidden.

Deviations allowed: none
